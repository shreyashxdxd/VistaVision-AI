# VistaVision AI

VistaVision AI is a real-time computer vision prototype designed to assist in emergency and rescue scenarios.

The system uses a live camera feed to detect people using YOLO and allows the user to capture a snapshot of an incident. The captured image can then be analyzed by an AI vision model to provide useful visual insights about the scene.

## Features

- Real-time camera feed
- Real-time human detection using YOLO
- Live bounding boxes around detected people
- Incident snapshot capture
- AI-powered image analysis
- Analysis of people, environment, visible hazards, and potential concerns

## How It Works

```
Live Camera
     ↓
YOLO Human Detection
     ↓
Live Bounding Boxes
     ↓
Capture Snapshot
     ↓
AI Vision Analysis
     ↓
AI Insights
```

## Running the Project

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/VistaVision-AI.git
cd VistaVision
```

### 2. Create and activate a virtual environment

```bash
python -m venv .venv
```

Windows:

```powershell
.venv\Scripts\ctivate
```

### 3. Install dependencies

```bash
pip install fastapi uvicorn ultralytics pillow google-genai python-dotenv python-multipart
```

### 4. Add your Gemini API key

Create a `.env` file in the project root:

```env
GEMINI_API_KEY=your_api_key_here
```

### 5. Start the backend

```bash
python -m uvicorn backend.main:app --reload
```

The backend will run at:

http://(Port number here)

### 6. Start the frontend

Open:

front-end/index.html

in your browser.

Allow camera access when prompted.

## Usage

1. Start the camera.
2. The system detects people in real time.
3. Bounding boxes appear around detected people.
4. Capture an incident snapshot.
5. Click **AI Analysis**.
6. The AI analyzes the captured image and displays the results.

## Disclaimer

This is a prototype intended for demonstration and development purposes.

AI analysis is based only on visible information in the captured image and should not be treated as a definitive assessment of an emergency, injury, or rescue situation.

# IBVAP – Intelligent Border Video Analytics Platform

## Frontend Development Requirements

### 1. Project Overview

I am developing a project called **IBVAP – Intelligent Border Video Analytics Platform**.

The purpose of this project is to transform existing standard CCTV/IP cameras into an AI-powered intelligent surveillance system for border security, check posts, Border Out Posts (BOPs), strategic roads, and other sensitive locations.

Traditional CCTV systems mainly provide live video and recording, which require continuous human monitoring. My project uses **Artificial Intelligence, Machine Learning, Computer Vision, and Video Analytics** to automatically analyze CCTV footage and generate useful security alerts.

The system should work mainly through software and should not depend on expensive dedicated smart cameras or specialized surveillance hardware.

---

# 2. Current Project Status

The **backend is already developed**.

The backend is responsible for processing the video and performing AI-based analytics. I now need to create a **professional frontend/desktop software interface** and connect it with my existing backend.

The frontend should display the live video and show the detection and analytics results generated by the backend.

Important: Before changing or rewriting any backend logic, first inspect the existing project structure and backend code. The frontend should integrate with the existing backend rather than replacing its functionality.

---

# 3. Main Goal for the Frontend

I do NOT want a normal website-style frontend.

I want the project to run like an actual **desktop surveillance software application**.

When I run the main project code:

1. A desktop application window should open.
2. The application should have a professional dark security/surveillance theme.
3. The main CCTV/sample video should play inside the application.
4. The existing backend should process the video.
5. AI detection results should appear on the video in real time.
6. A dashboard should display live analytics, alerts, and event logs.
7. The application should look like a real border security monitoring platform suitable for a hackathon demonstration.

Use **Python with PySide6** for the desktop frontend because the existing backend is Python-based.
